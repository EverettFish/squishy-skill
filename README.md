# 🫧 Squishy · 万物皆可捏

[English](README.en.md)

**把喜欢的东西，捏软一点。**

你家猫的臭脸、舍不得吃的小蛋糕、刚画好的小怪兽——给 AI 一张图，做成一只圆鼓鼓的桌面捏捏。按下去，瘪一点；松开手，慢悠悠地鼓回来。

不用学建模，也不用先装一堆东西。你负责挑一张喜欢的图，它负责把那一点喜欢变得软乎乎。

## 今天想捏什么？

### 🐈 把猫老板请到桌面上

上传一张猫猫照，说：“保留它那副不耐烦的表情，身体做成糯米团子。”

开会开累了，捏两下。它会慢慢鼓回来，现实里的猫也不用被你打扰。

### 🍰 把舍不得吃的甜点留下来

草莓蛋糕、布丁、奶油泡芙，或者你自己做的那块有点歪的小饼干。变成捏捏之后，热量归零，可爱照常。

### 🦖 让你的角色下班

给原创角色、游戏 NPC 或头像做一个软乎乎的小分身。平时负责拯救世界，今天只负责被捏扁、再努力站起来。

### 🎁 送一份不用拆快递的小礼物

“把这只小熊做成捏捏，旁边写：慢慢来，我等你。”

做好之后，可以在手机和电脑上玩。想把链接送出去，再让 AI 帮你发布；它不会默认公开你的照片。

### ✏️ 让一张随手画有了体积

小朋友的涂鸦、便签上的怪物、你乱画的小土豆。线条不必漂亮，有一点个性就够了。

## 你说一句，它做一只

> 用 $squishy 把这张图做成捏捏。先转成动森那种圆润可爱的 3D 画风，做三视图，再建模。我要白色背景，可以按压、转动、慢慢回弹。

大致会发生这些事：

1. **先认出它。** 留住颜色、表情、花纹和那些不能丢的小特征。
2. **让它圆起来。** 先画正面、侧面、背面，确保侧面也有肉，不是纸片玩偶。
3. **给它一副软身体。** 做成可编辑的 3D 模型，再赋予细腻的泡棉质感。
4. **留一点发呆的时间。** 打开干净的白色网页，按住、松手，看它慢慢恢复。

人物、动物和角色默认会被“团子化”：圆脑袋、鼓肚子、小短手，侧面也肉乎乎。松手时轻轻颤两下，再慢慢恢复；Blender 工程里也能直接播放这段 Q 弹小动作。

页面里没有一堆英文标签，也没有大大的 Logo 抢戏。主角是你的小东西。

## 装进口袋

这是一个给 AI 助手用的开源 **Skill**，不是需要注册的新应用。

**Codex：** 把仓库放到 `~/.codex/skills/squishy`，重新打开会话即可。

```sh
git clone https://github.com/EverettFish/squishy-skill.git ~/.codex/skills/squishy
```

**Claude Code 或其他支持 Skills 的助手：** 放进对应的技能目录，例如 `~/.claude/skills/squishy`。不支持技能目录的环境，也可以让助手读取仓库里的 `SKILL.md` 并按它完成任务。

然后上传图片，说：“把它做成捏捏。”

### 不用提前把工具凑齐

- **有生图工具：** 优先使用当前环境能调用的工具。Codex / ChatGPT 使用可用的内置 imagegen；其他环境使用已有的生图能力。
- **没有生图工具：** 直接参考原图继续建模，不会卡在让你填写 API Key 这一步。
- **没有 Blender：** 先找已有安装，再从 Blender 官方下载并校验便携版本。尽量装在用户目录里，不打扰系统配置。

电脑需要能够运行 Blender；助手也需要有执行代码、读写文件的能力。网页制作完成后，不需要生图额度或在线 API 才能玩。

## 做好后，你能带走什么？

- 一张可爱的三视图（生图工具可用时）。
- 一只真正有正面、侧面和背面的 3D 捏捏。
- 可以继续修改的 Blender 文件和建模脚本。
- 一个手机、电脑都能玩的白色小网页。
- 你喜欢的那句小小的安慰。

图片到模型由 AI 根据参考重新设计和建模，复杂角色、透明物体或遮挡较多的照片可能需要几轮调整。它是可玩的数字捏捏，不是照片的精密扫描件，也不是实体玩具生产文件。

## 一起多捏几种

欢迎带着猫、面包、奇怪的小生物来提 Issue。好的改进方向很简单：**更像、更圆、更想捏，页面再少一点。**
