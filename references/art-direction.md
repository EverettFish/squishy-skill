# From a picture to something you want to poke

Inspect the source first. Record five things that make it *this* subject: silhouette, colour blocks, distinctive face/markings, body proportions, and key accessories. For a person or pet, retain distinguishing features while simplifying into a cute toy. For food or objects, preserve their own geometry rather than forcing character anatomy.

For people, characters and animals, make the default proportions visibly mochi-like: short broad torso, big round cheeks/head, tiny limbs, and a side profile almost as plump as the front. As a starting point for a baby mascot, total height can be about 1.4–1.6 head heights and maximum width about .75–.85 of total height. Adjust to preserve identity; don't apply this anatomy to cakes or ordinary objects.

## Turnaround prompt

Adapt this brief with the actual subject and identity anchors:

> Use the attached image as identity reference. Reimagine [subject] as an adorable, rounded, fully three-dimensional slow-rising foam toy with the friendly proportions and tactile surfaces of a cozy life-simulation game. Keep [identity anchors]. Produce exactly three consistent orthographic full-object views: front, side, back, same scale, same pose, aligned ground plane. Pure white background, ample separation, no labels, logo, frame or scenery. The side must show genuinely substantial volume: [specific depth/profile]. Soft rounded transitions, short sturdy appendages where appropriate, matte finely porous foam, soft studio light. Preserve [accessories/markings]; don't invent [unwanted details]. This is a modeling reference sheet, not a website mockup.

No generic named artist is needed. When a user asks for Animal Crossing-like styling, translate that into round game-toy proportions, friendly faces, clean silhouettes, cozy colours and soft light; do not add the game's logos or unrelated character parts.

## Inspect before using

Check shared height/width, markings, limb count, facial expression, tail/accessories and side depth. Back-view inventions should be plausible and modest. Major drift gets a targeted correction; do not generate endless alternate sheets. If one view is usable and others contradict it, use it with the original and explicitly document the inferred hidden side.

Save `references/turnaround.png` and `references/turnaround-prompt.txt`, plus a short modeling note such as:

```
Total height 3.44; head width 2.56, depth 2.26, height 2.32.
Body width 2.2, depth 1.92; torso shortened into a round dumpling.
Face follows the round head surface; tiny feet barely emerge.
Tail extends backwards, not sideways like a 2D silhouette.
```

These are the Nailong example's measurements, not universal defaults.

If generation is unavailable, proceed with the original reference and those same observations. A single photo cannot determine unseen geometry; make a coherent toy interpretation without pretending to reconstruct it exactly.
